# Техническое задание

на курсовой проект «Туман — Языки России»

*Дисциплина «Введение в профессиональную деятельность», 2026*

## 1. Наименование проекта

**Полное наименование:** Android-приложение «Туман — Языки России» для
изучения языков коренных народов России с помощью карточек и
интервального повторения.

**Краткое наименование:** «Туман».

**Тема проекта:** Android-приложение для изучения языков коренных
народов России с интервальным повторением карточек.

## 2. Руководитель и исполнители

**Руководитель проекта:** Туяков М. С., магистрант группы K4240
Университета ИТМО. Руководитель ставит задачи, согласует решения и
принимает результаты этапов.

**Исполнитель:** проектная команда из 8 студентов первого курса

## 3. Сроки выполнения

Начало работ: 12 октября 2026 г. Окончание работ: 30 ноября 2026 г.

## 4. Цель проекта

Разработать Android-приложение «Туман» с готовыми наборами карточек по
башкирскому языку и адаптивным интервальным повторением для людей,
самостоятельно изучающих языки коренных народов России, чтобы они могли
регулярно заниматься без преподавателя и закреплять слова и
грамматические формы.

### 4.1. Актуальность

Многие языки коренных народов России теряют носителей: в городах ими всё
реже пользуются в быту, а тем, кто хочет выучить язык своей семьи или
региона, не хватает удобных материалов. Популярные приложения для
изучения языков почти не поддерживают языки народов России. При этом
такие языки, например башкирский с цепочками аффиксов, требуют
регулярного повторения: без него слова и формы быстро забываются. Метод
интервального повторения показывает материал тогда, когда он начинает
забываться, и считается одним из самых эффективных способов
долговременного запоминания, а игровые механики помогают заниматься
каждый день. ООН объявила 2022–2032 гг. Международным десятилетием
языков коренных народов.

### 4.2. Ценность проекта

- **Для пользователей:** готовые проверенные наборы для старта,
  индивидуальное расписание повторений, работа без интернета,
  напоминания, игровая мотивация и наглядный прогресс.

- **Для сохранения языков:** единый формат наборов позволяет добавлять
  другие языки народов России без изменения кода.

- **Для команды:** опыт полного цикла разработки мобильного приложения с
  серверной частью и работы с лингвистическим контентом; основа для
  дальнейшего развития проекта в Акселераторе.

## 5. Термины и сокращения

| **Термин**              | **Определение**                                                                                                                         |
|-------------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| Карточка                | единица запоминания: лицевая сторона (вопрос, слово) и обратная сторона (ответ, перевод), при необходимости — пример                    |
| Набор                   | группа карточек на одну тему                                                                                                            |
| Готовый набор           | набор, подготовленный командой и загружаемый из каталога на сервере                                                                     |
| Интервальное повторение | метод запоминания, при котором материал повторяется через увеличивающиеся промежутки времени незадолго до того, как он может быть забыт |
| FSRS                    | Free Spaced Repetition Scheduler — открытый алгоритм интервального повторения; в проекте используется его упрощённая версия             |
| Аффикс                  | часть слова, присоединяемая к корню (суффикс, окончание); в башкирском языке аффиксы выражают число, падеж и другие значения            |
| Серия (streak)          | число дней подряд, в которые пользователь выполнил дневную цель                                                                         |
| XP                      | очки опыта, начисляемые за повторение карточек                                                                                          |
| Серверная часть         | программа на сервере, которая хранит каталог готовых наборов и отдаёт их приложению                                                     |
| MVP                     | минимально жизнеспособная версия продукта, достаточная для демонстрации основного сценария                                              |
| APK                     | установочный файл Android-приложения                                                                                                    |

## 6. Требования к проекту

**Потребители результата:** школьники, студенты и взрослые,
самостоятельно изучающие башкирский язык; в перспективе — изучающие
другие языки коренных народов России. Заказчик учебной работы:
Университет ИТМО.

### 6.1. Функциональные требования

| **№** | **Модуль**        | **Требование**                                                                                                                                                         |
|-------|-------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ФТ-1  | Наборы и карточки | Приложение должно позволять создавать, переименовывать и удалять наборы.                                                                                               |
| ФТ-2  | Наборы и карточки | Приложение должно позволять создавать, редактировать и удалять карточки с полями «лицевая сторона», «обратная сторона» и необязательным полем «пример».                |
| ФТ-3  | Наборы и карточки | При вводе текста карточки приложение должно предоставлять панель для ввода букв башкирского алфавита (ә, ө, ү, ғ, ҡ, ң, ҙ, ҫ, һ).                                      |
| ФТ-4  | Готовые наборы    | Приложение должно показывать каталог готовых наборов с сервера и позволять загрузить выбранный набор на устройство.                                                    |
| ФТ-5  | Повторение        | Приложение должно формировать список карточек «на сегодня» по упрощённому алгоритму FSRS.                                                                              |
| ФТ-6  | Повторение        | Приложение должно показывать лицевую сторону карточки, по нажатию — обратную, и принимать оценку ответа по четырём градациям: «не помню», «трудно», «хорошо», «легко». |
| ФТ-7  | Повторение        | По оценке ответа приложение должно пересчитывать дату следующего показа карточки и сохранять ответ в истории.                                                          |
| ФТ-8  | Мотивация         | Приложение должно позволять задать дневную цель (число карточек в день) и вести серию дней её выполнения.                                                              |
| ФТ-9  | Мотивация         | Приложение должно начислять XP за повторённые карточки и присваивать не менее 5 достижений (например, первый набор, 7 дней подряд, 100 выученных карточек).            |
| ФТ-10 | Прогресс          | Приложение должно показывать экран прогресса: число выученных карточек, долю верных ответов, текущую и лучшую серию, XP.                                               |
| ФТ-11 | Напоминания       | Приложение должно отправлять ежедневное уведомление о карточках к повторению в выбранное время; уведомления можно отключить.                                           |
| ФТ-12 | Серверная часть   | Серверная часть должна отдавать список готовых наборов и содержимое выбранного набора в формате JSON.                                                                  |

### 6.2. Требования к готовым наборам

- Каталог MVP должен содержать не менее 3 готовых наборов по башкирскому
  языку (например, «Базовые слова», «Фразы на каждый день», «Аффиксы»),
  всего не менее 100 карточек.

- Переводы и примеры должны быть сверены не менее чем с двумя
  источниками (словари, учебники); список источников прикладывается к
  результатам.

- Наборы хранятся в едином формате JSON, описание формата
  прикладывается, чтобы наборы по другим языкам и предметам можно было
  добавить без изменения кода.

### 6.3. Нефункциональные требования

| **Категория**        | **Требование**                                                                                                                                                                                                                            |
|----------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Платформа            | Приложение должно работать на Android 8.0 (API 26) и выше. Рекомендуемый стек: Kotlin (Jetpack Compose), Room (SQLite), WorkManager; стек может быть уточнён командой по согласованию с руководителем.                                    |
| Работа без интернета | Все функции, кроме загрузки готовых наборов, должны работать без интернета. Загруженный набор должен быть доступен без сети. При отсутствии сети каталог должен показывать понятное сообщение.                                            |
| Производительность   | Запуск приложения — не более 4 с; переход к следующей карточке — не более 1 с.                                                                                                                                                            |
| Надёжность           | Наборы, карточки, история ответов и прогресс должны сохраняться после перезапуска приложения. Ошибки сети не должны приводить к аварийному завершению.                                                                                    |
| Удобство             | Начать повторение можно с главного экрана одним нажатием. Приложение должно отображать все буквы башкирского алфавита (ә, ө, ү, ғ, ҡ, ң, ҙ, ҫ, һ) на всех экранах без замены на пустые квадраты или знаки «?». Язык интерфейса — русский. |
| Расширяемость        | Алгоритм повторения должен быть отдельным модулем, независимым от интерфейса.                                                                                                                                                             |
| Ограничения MVP      | В MVP не входят: iOS, регистрация и синхронизация между устройствами, ИИ-собеседник, озвучка слов, распознавание текста с фото, платные функции. Это направления развития после защиты.                                                   |

## 9. Критерии приёмки

1.  Приложение устанавливается из APK на Android 8.0+ и запускается без
    ошибок.

2.  Наборы и карточки создаются, редактируются и удаляются; все буквы
    башкирского алфавита вводятся с панели и отображаются без замены на
    квадраты или «?».

3.  Из каталога загружаются 3 готовых набора по башкирскому языку (100+
    карточек) и доступны без интернета.

4.  После оценки ответа меняется дата следующего показа карточки; это
    подтверждено юнит-тестами алгоритма.

5.  Дневная цель, серия дней, очки опыта и не менее 5 достижений
    начисляются по заданным правилам и видны на экране прогресса.

6.  Ежедневное напоминание приходит в выбранное время и отключается.

7.  Протокол приёмочного тестирования подтверждает требования раздела 6;
    критических дефектов нет.

8.  Продемонстрирован сценарий: загрузка готового набора → повторение →
    экран прогресса.
