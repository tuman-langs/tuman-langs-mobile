# Чек-лист проверки приложения по ТЗ

По этому чек-листу принимаются задачи и проводится приёмочное тестирование перед защитой (этап 9 ТЗ). Каждая строка ссылается на требование из раздела 6 `docs/tz.md`: так на приёмке видно, что проверено всё.

Ответственный: Михеев В. Задача: [#7](https://github.com/tuman-langs/tuman-langs-mobile/issues/7).

## Как пользоваться

1. Скопируйте таблицы в комментарий к задаче или в протокол проверки и заполните шапку ниже.
2. Выполняйте шаги буквально, по порядку. Если шаг невозможно выполнить (экрана ещё нет), ставьте ⏭ и пишите почему.
3. В колонке «Результат» ставьте:
   - ✅ — получилось то, что в «Ожидаемом результате»;
   - ❌ — получилось иначе: заведите задачу по шаблону «Ошибка» (New issue → «Ошибка») и впишите её номер, например «❌ #31»;
   - ⏭ — не проверялось.
4. Названия кнопок и экранов уточняются по макетам в Figma. Если в приложении кнопка называется иначе, но делает то же — это не ошибка, поправьте шаги в чек-листе.

**Подготовка**

- Эмулятор Android 8.0 (API 26): Android Studio → Device Manager → Create Virtual Device → любой телефон → System Image: API 26 → Finish.
- Если есть — свой телефон с Android 8.0 или новее.
- Перед проверкой приложение удалено и установлено заново из APK этой сборки, если в строке не сказано иное.
- Буквы башкирского алфавита для проверок: **ә ө ү ғ ҡ ң ҙ ҫ һ** (заглавные: **Ә Ө Ү Ғ Ҡ Ң Ҙ Ҫ Һ**).
