# Сверка экранов «Тумана» с макетами — #38

**Итог.** На Android 15 проверены 29 состояний из макетов. Подтверждены расхождения, в том числе отсутствие входа в каталог из пустого списка наборов, отличия подсказки к оценкам и упрощённый итог сессии.

Дата проверки — 22.11.2026. Перечень состояний взят из [design/README.md](../../design/README.md), макеты — из [design/index.html](../../design/index.html). Целевая версия приложения — `main` (`da5a980`).

Команда `./gradlew test assembleDebug` завершилась успешно для целевой версии. В Gradle прошли 74 теста приложения в debug, 74 в release и 22 теста `core-srs`.

Снимки «Сборка main» получены из APK `da5a980` на эмуляторе Pixel 6, Android 15 (API 35), с новым профилем. В каталоге ошибку скачивания вызвали отключением сети перед нажатием кнопки при открытом списке. Обрыв уже начавшейся передачи отдельно не проверялся.
