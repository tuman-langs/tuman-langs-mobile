# Продукт «Туман»

## Проблема и ценность

Многие языки коренных народов России теряют носителей. Тем, кто хочет выучить язык семьи или региона, не хватает удобных материалов, а популярные приложения почти не поддерживают эти языки. Языки с богатой морфологией (например, башкирский с цепочками аффиксов) требуют регулярного повторения, иначе слова и формы быстро забываются.

- **Для пользователей:** готовые проверенные наборы для старта, индивидуальное расписание повторений, работа без интернета, напоминания, игровая мотивация, наглядный прогресс.
- **Для сохранения языков:** единый формат наборов позволяет добавлять другие языки без изменения кода.
- **Для команды:** полный цикл разработки мобильного приложения с серверной частью; основа для развития в Акселераторе.

**Потребители:** школьники, студенты и взрослые, самостоятельно изучающие башкирский; в перспективе — другие языки коренных народов России.

## Основной сценарий для демонстрации

Загрузить готовый набор из каталога → пройти повторение «на сегодня» с оценками → увидеть экран прогресса (серия дней, XP, достижения). Всё, кроме загрузки, — в режиме полёта.

## Алгоритм: упрощённый FSRS

FSRS (Free Spaced Repetition Scheduler) — открытый алгоритм интервального повторения, используется по умолчанию в Anki с 2023 года. Вместо одной пары «интервал + коэффициент лёгкости», как в SM-2, для каждой карточки ведутся три величины:
- **Difficulty** — сложность карточки для этого пользователя;
- **Stability** — устойчивость воспоминания в днях;
- **Retrievability** — текущая вероятность вспомнить.

После каждой оценки величины пересчитываются по открытым формулам, а следующий показ назначается так, чтобы к нему вероятность вспомнить была около целевой (например, 90%).

Требования к реализации:
- отдельный модуль без зависимостей от UI и Android (чистый Kotlin), чтобы тестировать его юнит-тестами;
- вход: история ответов карточки и текущая дата; выход: дата следующего показа и обновлённые параметры;
- юнит-тесты на каждую из 4 оценок, на новую карточку и на длинную серию ответов.

Перед реализацией сверить формулы с актуальной открытой спецификацией FSRS — не по памяти модели.

## Черновик формата набора (JSON)

Окончательный формат описывает контент-лид. Стартовая точка для обсуждения:

```json
{
  "id": "ba-basic-words",
  "language": "ba",
  "title": "Базовые слова",
  "description": "Частотные слова для начала",
  "version": 1,
  "sources": ["Башкирско-русский словарь, ...", "..."],
  "cards": [
    {
      "id": "ba-basic-0001",
      "front": "китап",
      "back": "книга",
      "example": "Был китап — минең китабым.",
      "tags": ["существительное"]
    }
  ]
}
```

Пример выше показывает только структуру; слова и перевод в нём не проверены.

Требования из ТЗ: минимум 3 набора (например, «Базовые слова», «Фразы на каждый день», «Аффиксы»), всего 100+ карточек; каждый перевод сверен минимум с двумя источниками; формат описан, чтобы добавлять языки без изменения кода.

## Предлагаемая структура репозитория

```
/               корень = проект Android Studio (settings.gradle.kts, gradlew, CLAUDE.md)
/app            модуль приложения: экраны, база Room, напоминания
/core-srs       модуль алгоритма повторения (чистый Kotlin, без Android) + юнит-тесты
/design         ссылки на Figma, экспорт ключевых экранов
/docs           документация проекта (этот каталог)
/.github        шаблоны задач и PR
/.claude        общие настройки и команды Claude Code
```

Наборы карточек (`content/`) и сервер каталога живут в отдельном репозитории `tuman-langs/tuman-langs-backend`.

`core-srs` — отдельный Gradle-модуль (File → New → New Module → Java or Kotlin Library). Так выполняется требование ТЗ «алгоритм — отдельный модуль, независимый от UI», и его можно тестировать без эмулятора.

## Идеи после MVP (не делать сейчас)

ИИ-собеседник на башкирском, уроки с разными типами упражнений, озвучка, другие языки, синхронизация между устройствами, распознавание текста с фото. Если захочется добавить в MVP небольшой ИИ-элемент (первокурсники учатся на ИИ-программах), это можно оформить дополнительным соглашением к ТЗ до 10 ноября — например, генерацию примеров предложений к карточкам с обязательной проверкой лингвистом.
