# Туман — Языки России

Android-приложение для изучения языков коренных народов России (в MVP — башкирского) с карточками, адаптивным интервальным повторением и игровыми механиками. Курсовой проект ИТМО, 12 октября – 30 ноября 2026.

## С чего начать

1. Пройдите `docs/onboarding.md` — доступы, установка, как взять первую задачу.
2. Прочитайте `CLAUDE.md` — там суть проекта, команда, правила и даты.
3. Найдите свою роль и задачи в `docs/team.md`.
4. Как брать задачи и оформлять PR — `docs/kanban-workflow.md`.
5. Как работать через Claude и что писать в декларации ИИ — `docs/claude-for-team.md`.
6. Требования к продукту — `docs/tz.md` (утверждаемое ТЗ, менять нельзя без руководителя).
